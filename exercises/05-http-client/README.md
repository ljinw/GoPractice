## 本题常用写法（遇到再看）

```go
resp, err := client.Get(url)
```

- 【习惯】`client` 是客户端，`resp` 是响应，`err` 是错误；Go 不强制这些名字。
- 【库合同】先处理 err，再使用 resp；`err == nil` 不代表状态码一定是 200。
- 【常见资源管理】请求成功后安排 `defer resp.Body.Close()`，在函数返回时释放正文资源；需要关注 Close 错误时用函数包装并检查。
- 【常见单位】超时写成 `2 * time.Second`，使单位清楚；裸数字赋给 time.Duration 的单位是纳秒。Client 一般可复用。
