# 48 · 交付一个能演示和复现的巡检助手

阶段：业务整体验收。前置：第 47 题；第 47 题的 live 可独立保持未验证。

## 先学再练：本题串讲

打开本目录的 [知识串讲](知识串讲.md)，先学这题需要的语法、原理和常用写法，再回来实现下面的业务需求。

配套：[多轮练习册：变式、排错、源码与C#](练习册.md)。先完成当前小步骤，再按练习册安排重复与复习。

## 业务为什么需要它

库都用过以后，需要证明它们共同解决了一个完整问题。

## 这次做成什么

从登记设备走到报告、AI 分析和报告通知，并验证故障恢复。

## 具体需求

编写可重复运行的本地演示与自动回归入口。场景：登记 sw-core→提交巡检→后台执行→查询证据报告→Eino 分析并引用知识→本机收到报告就绪通知。默认 fake；live 是第 47 题独立标记。使用独立临时数据，记录命令、状态码、任务/报告编号、日志与实际断言。

## 输入与结果

```text
用户能解释：什么异常、证据在哪、为何这样判、下一步做什么
```

## 怎样算完成

- [ ] 正常/异常/未知三条业务场景都能完整执行，编号能串起证据。
- [ ] 越权、重复请求、Redis 中断、worker 退出、模型坏输出各有失败与恢复测试。
- [ ] README 能指导他人启动和复现；通过、失败、跳过和 fake/live 边界写清。

## 本题常用写法（遇到再看）

【交付习惯】验收按业务行为，技术栈列表只说明用了什么。【范围】这套本地练习的完成不等于 E:\NetMon 上线或现网验收。
