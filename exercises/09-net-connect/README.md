## 这次做成什么

判断一个明确指定的本机 TCP 端口能否建立连接。

## 具体需求

目标固定 127.0.0.1，只允许一个端口，不做扫描。用 net.DialTimeout 设置 1 秒连接超时；成功立即关闭连接，失败保留原因。可以连接仍在运行的第 01 题服务；TCP 连接成功不等于 HTTP 业务健康。

## 输入与结果

```text
第 01 题运行，检查 127.0.0.1:18080 → connected
关闭该服务再检查 → failed + 原因
```

## 怎样算完成

- [ ] 本机服务运行时成功；关闭时失败。
- [ ] 端口 0、-1、70000 先报输入错误，不尝试连接。
- [ ] 连续运行 20 次能结束且释放每次连接；连接耗时受超时限制（不要求恰好 1 秒）。

## 本题常用写法（遇到再看）

```go
conn, err := net.DialTimeout("tcp", address, time.Second)
```

- 【习惯】`conn` 是 connection 的常见缩写；成功后它代表一条连接。
- 【库合同】连接成功后由使用方负责 Close；失败时先处理 err，不能直接调用 conn 的方法。
- 【常见组合】用 JoinHostPort 组合主机和端口，比自己拼冒号更通用；端口文本可用 strconv.Itoa 转换。
- 【常见错误处理】错误里补充“连接哪个本机端口失败”，同时保留原始原因；不要只输出一个没有上下文的 failed。
