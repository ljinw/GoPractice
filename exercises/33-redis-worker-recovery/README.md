## 业务为什么需要它

进程可能在执行一半时退出，任务不能永远卡住。

## 这次做成什么

让超期任务可恢复，并阻止旧 worker 覆盖新结果。

## 具体需求

增加执行租约、attempt、执行代号；到期后可重新领取，最多 3 次。结合 pending 消息回收；只允许持有当前执行代号的 worker 提交事实和报告。可重试故障重新排队，到上限标记 failed；消息确认与恢复依据数据库事实协调。执行代号条件必须与结果写入在同一事务。

## 输入与结果

```text
worker A 领取后停止 → 租约到期 → B 完成；A 迟到的写入被拒绝
```

## 怎样算完成

- [ ] 模拟时钟到期，卡住的任务能够重新执行。
- [ ] 旧 worker 在新 worker 完成后回写失败，报告只有一份。
- [ ] 连续 3 次失败变成最终 failed，不无限重试；原因可查询。

## 本题常用写法（遇到再看）

【常见名字】lease、attempt、backoff、fencing token。【边界】不是加一把 Redis 锁就自动获得全链路一致性。
