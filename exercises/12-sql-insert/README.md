## 这题在完整业务中的位置

设备登记：把一台设备真正保存下来。 [查看完整业务](../../业务主线.md)。

## 这次做成什么

把合法设备写入数据库并得到新增 ID。

## 具体需求

新增一台设备需要非空 name 和合法 IPv4；name 去除两端空白，ip 以解析后的 IPv4 标准文本保存。enabled 默认 1。用带 ? 占位符的 INSERT 与参数传递；重复 IP 返回可识别的冲突错误。输入先用函数参数或 main 中的假数据，无需 HTTP。

## 输入与结果

```text
name=sw-core，ip=192.0.2.10 → 新增 ID
再次插入相同 IP → conflict
```

## 怎样算完成

- [ ] 插入一次后表行数增加 1，返回有效 ID。
- [ ] 同 IP 重试行数不再增加；空 name 或坏 IP 不写入。
- [ ] 名称 O'Reilly-switch 可原样保存，证明没有靠拼字符串生成 SQL。

## 本题常用写法（遇到再看）

```sql
INSERT INTO devices (name, ip) VALUES (?, ?)
```

- 【SQL 常见排版】关键字大写、表和列用小写便于阅读；这里的大小写排版不是 Go 语法要求。
- 【库合同】? 是 SQLite 的参数占位符，值通过 ExecContext 的参数传入；其他数据库的占位符写法可能不同。
- 【习惯】`result` 常接收执行结果；先检查执行错误，再调用 LastInsertId，并处理它自己的错误。
- 【命名习惯】Go 中常写 `deviceID`、结构体字段 `ID`，而不是混用 Id、id、ID 多套缩写风格。
