## 这次做成什么

按 ID 删除练习数据库中的一条设备。

## 具体需求

DeleteDevice 只接受正 ID，用 DELETE ... WHERE id = ?。本题约定：已删除或不存在返回 deleted=false、无错误；存在且删除返回 deleted=true。数据库故障返回 error。只能使用当前题目自己生成的数据库。

## 输入与结果

```text
删除现有 ID → true
再删相同 ID → false，无错误
```

## 怎样算完成

- [ ] 目标删除后查不到，另一设备仍存在。
- [ ] 重复删除不报系统错误，也不改变其他行。
- [ ] 0、负 ID 拒绝；数据库关闭时返回错误。

## 本题常用写法（遇到再看）

签名读法示意：

```go
DeleteDevice(ctx context.Context, id int64) (bool, error)
```

- 【习惯】多返回值中 error 放最后，bool 的业务含义应写进函数注释。
- 【本题合同】true 表示删掉了一条；false 且无错误表示目标已不存在。换一个项目，约定可能不同。
- 【常见用法】先看 error，再看 bool；不能用“没有报错”推断一定删掉了一条。
- 【语法】`return false, err` 同时返回两个值；顺序必须与函数声明一致。
