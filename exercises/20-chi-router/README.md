## 本题常用写法（遇到再看）

```go
router.Get("/devices/{id}", h.getDevice)
```

- 【习惯】router 表示路由器；也常见变量 r。本题用 router，便于与处理器中的请求 r 区分。
- 【库合同】chi 的处理函数仍是 `func(w http.ResponseWriter, r *http.Request)`。
- 【常见用法】`chi.URLParam(r, "id")` 读取路径变量；参数名要与路由里的 {id} 对应。
- 【语法】同样是传入 h.getDevice，不是在登记路由时调用它；已经写好的业务函数可以继续使用。
