## 这次做成什么

亲手完成一次 TCP 的发送和接收。

## 具体需求

服务只监听 127.0.0.1:19090；客户端发送 ping\n，服务返回 pong\n。其他完整行返回 unknown\n。每条连接只处理一行然后关闭；先串行处理。设置 2 秒读写期限；无换行或提前断开不能一直挂住，也不能让服务永久退出。

## 输入与结果

```text
客户端：ping\n
服务端：pong\n
```

## 怎样算完成

- [ ] ping 和 hello 分别得到 pong 与 unknown。
- [ ] 客户端不发换行：期限到后结束该连接。
- [ ] 一个客户端异常断开后，下一个正常客户端仍能成功。

## 本题常用写法（遇到再看）

```go
ln, err := net.Listen("tcp", address)
```

- 【习惯】`ln` 或 `listener` 指监听器，`conn` 指 Accept 得到的某一条连接；它们各自有关闭时机。
- 【库合同】`SetDeadline` 接收一个具体时间点，常写 `time.Now().Add(2 * time.Second)`，并检查返回错误。
- 【协议约定】本题用换行分隔消息；TCP 本身提供字节流，不知道“ping 是一整条消息”。
- 【常见组织】把单条连接的处理放进独立函数，在那里释放资源；不要把循环内的所有 Close 都 defer 到长期运行的外层函数。
