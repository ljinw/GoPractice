## 本题常用写法（遇到再看）

```go
func TestDevicePreview(t *testing.T) {
    // 准备输入，调用处理器，检查结果。
}
```

- 【工具合同】测试放在 `xxx_test.go`；测试函数采用 TestXxx(t *testing.T) 的形式，Xxx 以大写字母开头是常用写法。
- 【习惯】`got` 表示实际结果，`want` 表示期望；它们只是变量名。
- 【常见写法】用表格驱动测试列出正常、空值、坏 JSON；用 `t.Run` 给每种情况起名字。第一轮可以先写一个单独测试。
- 【库合同】`t.Fatal/Fatalf` 结束当前测试的执行，`t.Error/Errorf` 记录失败后继续；不用 panic 代替正常测试断言。
