## 业务为什么需要它

模拟测试能验证程序流程，但不能证明实际模型输出质量。

## 这次做成什么

在明确授权与预算下验证一个真实模型适配器。

## 具体需求

执行前由用户确认供应商、模型、发送的合成样例与单次预算；未确认只做适配和无网络检查，标记 live 未验证。密钥读本地环境变量，通过现有 Eino ChatModel 适配器进入唯一分析入口。限制输入、输出、超时和至多一次额外重试；记录模型标识、耗时、可取得的用量和失败原因。

## 输入与结果

```text
同一 CPU=92 合成报告 → live 分析；原 fake 自动测试仍可无密钥运行
```

## 怎样算完成

- [ ] 无密钥或未授权时明确不可进行 live，不自动选供应商。
- [ ] 获准调用后能验证引用与建议，并记录实际请求结果，不能只展示示例文案。
- [ ] 超时、配额或坏输出保持失败语义；不把真实密钥写入代码、报告或日志。
