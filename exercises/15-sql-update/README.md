## 这题在完整业务中的位置

维护资料：允许更正名称而不影响其他设备。 [查看完整业务](../../业务主线.md)。

## 这次做成什么

只修改指定 ID 的设备名称。

## 具体需求

UpdateName 接收 ID 与新名称；名称去空白后不能为空。UPDATE 使用 WHERE id = ?。不存在 ID 返回 not found；空名称不修改；相同名称重复提交可以成功，不能生成新设备。ip 与 enabled 保持原值。

## 输入与结果

```text
id=1，name=sw-renamed → 该设备名称更新
id=不存在 → not found
```

## 怎样算完成

- [ ] 只更新目标，另一条设备完全不变。
- [ ] 空白 name 被拒绝，原名称还在。
- [ ] 不存在 ID 不增加行；同名称重复提交后总行数不变。

## 本题常用写法（遇到再看）

```sql
UPDATE devices SET name = ? WHERE id = ?
```

- 【参数合同】传参顺序与占位符顺序对应：先新名称，再 ID；变量在 Go 中叫什么不会改变绑定顺序。
- 【常见习惯】修改和删除时先确认 WHERE 范围，再检查受影响行数。
- 【库合同】`RowsAffected()` 自己也返回 error，不能只检查前面的 ExecContext。
- 【业务约定】“同一个名称再提交可以成功”是本题决定的行为；不能把“值没变化”随意判为不存在。
