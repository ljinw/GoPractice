# 45 · 让 Agent 自己选择只读查询工具

阶段：Eino Agent / Tools。前置：第 44 题。

## 业务为什么需要它

用户可能继续追问异常细节，需要按问题补查资料。

## 这次做成什么

让 Agent 在固定权限内调用报告和知识查询工具。

## 具体需求

使用 Eino 的 Agent 能力，先配假模型脚本驱动工具调用。工具仅 get_report 与 search_knowledge；服务端注入用户身份，工具内部再授权，参数有类型校验。限制总时长、轮数最多 4 次与工具调用最多 4 次；不提供设备命令执行或任意文件读取工具。工具返回资料是数据，不是可覆盖规则的指令。

## 输入与结果

```text
问“为什么认为异常” → get_report；问“下一步检查什么” → search_knowledge
```

## 怎样算完成

- [ ] 工具调用和引用能追溯到本次问题及当前用户。
- [ ] 伪造他人 report_id、未知工具名或多余参数会被拒绝。
- [ ] 超过轮次或超时能结束；模型诱导执行设备写入时没有可用写工具。

## 本题常用写法（遇到再看）

【常见词】Tool schema、AgentEvent、Runner、max steps。【边界】工具白名单和权限由代码决定，不能只靠提示词。
