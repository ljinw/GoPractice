## 这次做成什么

使用 net 库给设备资料增加 IPv4 校验。

## 具体需求

先写可单独测试的校验函数，去除输入两端空白后用 net.ParseIP 和 To4 判断；IPv4 文本通过，IPv6 地址文本（包含冒号）在本题明确拒绝。随后让 POST /device-preview 对非法 ip 返回 400。这里判断的是格式，不判断设备是否存在。

## 输入与结果

```text
192.0.2.10 → 通过
999.1.1.1、sw-core、空字符串、2001:db8::1 → 不通过
```

## 怎样算完成

- [ ] 192.0.2.10、198.51.100.20 通过。
- [ ] 空值、非法数字、主机名、IPv6 文本均失败。
- [ ] 有效 name + 非法 ip 得到 400；有效两字段得到 200。

## 本题常用写法（遇到再看）

```go
ip := net.ParseIP(text)
```

- 【库合同】ParseIP 只返回一个 IP 值，失败返回 nil；它没有第二个 error 返回值。遇到新函数先看签名。
- 【习惯】局部变量常写 `ip`；组合字段名常写 `DeviceIP`，保持 IP 缩写的大小写一致。
- 【常见处理】`ip == nil` 时先返回校验失败，再继续判断地址类型。
- 【业务约定】本题只收 IPv4 文本；ParseIP 本身也支持 IPv6，不能把本题限制误认为库的限制。
