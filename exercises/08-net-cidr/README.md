## 这次做成什么

给一个 IP 和 CIDR，返回属于、不属于或输入错误。

## 具体需求

写 InSubnet(ipText, cidrText string) (bool, error)，只处理 IPv4。IP 和 CIDR 先去两端空白；CIDR 可带主机位，由解析器确定所属网段。非法 IP/CIDR 返回 error；合法但不属于返回 false、nil。只做地址运算。

## 输入与结果

```text
192.0.2.10 + 192.0.2.0/24 → true, nil
198.51.100.10 + 192.0.2.0/24 → false, nil
192.0.2.10 + 192.0.2.0/33 → error
```

## 怎样算完成

- [ ] 同网段 true，不同网段 false。
- [ ] /32 只包含那个 IP；192.0.2.128 不属于 192.0.2.0/25。
- [ ] IP 或 CIDR 为空、IPv6、非法掩码均报输入错误。

## 本题常用写法（遇到再看）

```go
_, subnet, err := net.ParseCIDR(cidrText)
```

- 【库合同】三个返回值依次是解析出的 IP、所属网段、错误；本题只需要后两项。
- 【语法】`_` 是空白标识符，明确丢弃一个结果；不要用它顺手丢弃需要处理的错误。
- 【习惯】自己的函数常把 error 放在最后：`(bool, error)`；调用时先看错误，再解释 bool。
- 【命名选择】`subnet` 或 `network` 都可以；名字应帮助你区分“一个地址”和“一个地址范围”。
