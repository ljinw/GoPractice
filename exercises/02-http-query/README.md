## 本题常用写法（遇到再看）

```go
name := r.URL.Query().Get("name")
```

- 【语法】`:=` 声明并赋值，类型由右边推断；已有变量再次赋值通常用 `=`。
- 【库合同】先取 URL，再调用 Query() 得到参数集合，最后 Get("name") 得到字符串；缺少 name 时是空字符串。
- 【习惯】变量用 `name`、`deviceName` 这类能看懂的名称；URL 中的 name 是我们约定的参数名。
- 【常见处理】先整理输入，再判断是否合法；`TrimSpace` 只删除两端空白。此处知道每一步输入输出就够了。
